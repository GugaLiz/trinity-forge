## 对反馈建议的必要调整

1. **终点不提供假线索。** 当前 28 个配方中，陶、雨均没有后续。反馈用「陶 + ?」举例的意图是提供方向；本轮将其落实为真实分支或终点标记，不新增不存在的配方，也不提示产物可以互相合成。
2. **免费操作不能刷生态收益。** 非推进操作仅应用其直接成本/恢复，不触发生态回补、反噬或抽牌；这样试探的成本才可控且有限。
3. **调息冷却要有兜底。** 只允许每三回合免费恢复，会让连续试错耗尽养分的玩家无法推进。保留耗一回合的休整选项，按钮明确显示本次免费还是收费。
4. **失败不耗回合是常规规则。** 寻道和炼化均采用本轮 P0 新规则；大师作为明确标识的挑战例外保留回合惩罚。寻道与三回合的「入炉修习」教学分开命名。
5. **同回合操作也必须去重。** 命令校验回合号和操作版本，每次提交后版本递增；存档记录每条操作是否推进回合，刷新不重置试探记录或免费调息冷却。

## 首页难度入口修复

已有大师存档时，旧首页即使选中寻道，主按钮仍然是续玩旧局，造成难度切换未生效的观感。现已调整：不同难度被选中时主按钮改为开启该难度新局，旧局有明确标注难度的续玩入口；新局确认显示目标难度、回合数和将替换的旧难度，并固定本次请求的难度。取消不动旧局，明确续玩则同步首页选中项。

已补充六种跨难度切换（含选择后刷新、新局后恢复）及取消后保留/继续旧局的回归验证。浏览器流程总计 27 项通过。
