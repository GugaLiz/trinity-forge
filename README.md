# 三生炉 · Trinity Forge

移动端竖屏 H5 回合制合成小游戏。投入水、火、土，在 12 回合内发现至少 8 种产物。包含 28 个配方、3 回合教学、环境与反噬、历史图鉴、固定种子演示、音效和回合自动保存。

## 本地运行

需要 Node.js **22.12 以上**及 pnpm。项目使用 pnpm-lock.yaml 固定依赖。

```powershell
pnpm install
pnpm dev
```

访问 http://localhost:5173 。同一局域网手机可访问终端输出的 Network 地址。开发服务监听 0.0.0.0，若手机无法访问，检查本机防火墙和网络隔离。

当前开发机默认 Node 为 14；已安装的 Codex 运行时内有 Node 24。该机器可以直接运行 `./scripts/dev.ps1`，脚本会选取满足要求的 Node 并启动已安装的开发服务，不修改系统 Node 配置。

## 操作

- 新玩家可先点「入炉修习」，3 回合学习蒸汽 → 云 → 雨。
- 点材料按顺序入炉，点输入槽撤回；通过槽位序号与左右箭头调整顺序。
- 确认合成后，炉火、水汽与炉体摇晃展示约 1.3 秒；每次都会停留在结果面板，显示投入材料、产物、发现得分及资源变化。确认后切到生态区继续使用产物；失败与反噬会单独说明。
- 基础元素的 9 个配方无序匹配；其余配方必须先投入生态产物，再投入元素。
- 在「基础元素 / 生态产物」之间切换，已投材料保留。成功合成消耗前置产物。
- 养分不足可调息；槽位进入危险值会损失一个生态产物。具体规则见 [规则说明](docs/rules.md)。
- 每回合完整结算后自动保存，刷新后点「续燃炉火」。未确认的投料需重选。历史图鉴和成绩仅保存在当前浏览器；清理网站数据会移除进度。
- 设置里可以切换音效、减少动态、查看规则，或开启种子 `20261106` 的演示局。
- 「减少动态」或系统减少动态偏好会停用摇晃、粒子等效果，并缩短等待；合成期间刷新仍能恢复已结算进度，不会重复扣费。

## 验证

```powershell
pnpm test             # 配方、环境边界、结算、恢复、完整路线回放
pnpm test:routes      # 从真实手牌搜索 10 个种子的通关路线及 7 个第三层目标
pnpm exec playwright install chromium
pnpm test:e2e         # 移动触控视口的教学、通关、刷新、调序、小屏检查
pnpm build           # 类型检查 + 生产构建
pnpm preview         # 访问生产构建，默认端口 4173
```

路线证书见 [verified-routes.json](docs/verified-routes.json)，验证范围与未完成验收见 [验证记录](docs/playtest.md)。自动路线搜索知道所有配方，不代表首次玩家的通关率。

## 部署 H5

1. 执行 `pnpm build`，将 **dist 目录内全部文件**一起部署到静态托管服务。
2. 首页为 index.html；没有服务端或外部 API 依赖。配置了相对资源路径，可放在域名根目录或子目录。
3. 建议使用 HTTPS；index.html 使用短缓存或每次验证，带哈希的 assets 文件可长期缓存。更新时保留完整的同次构建资源，避免新旧页面与脚本混用。
4. 在实际手机访问部署地址，检查资源、刷新、声音启用、前后台恢复、安全区及继续游戏。浏览器更换或域名/协议变化会使用不同的本地存储。

正式托管地址尚未配置；不需要微信/抖音小游戏包或平台 SDK。

## 工程

- `src/game/`：配方、参数、种子随机数、纯函数回合引擎。
- `src/ui/`：React 界面、内嵌 SVG 纹章与炉体、可关闭且支持键盘焦点管理的弹层。
- `src/storage/`：版本化、校验后的历史与局中存档。
- `src/platform/`：交互触发的合成音效与后台暂停。
- `src/styles/`：390×844 基准竖屏布局、窄屏降级、安全区与减少动态。

实现依据为 [开发计划](关于游戏/开发plan-v1.0.md)；玩法数值集中在 `src/game/config.ts`，28 个节点集中在 `src/game/recipes.ts`。
